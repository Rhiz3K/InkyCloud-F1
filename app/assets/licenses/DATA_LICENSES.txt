Keep each component's source and licence with redistribution. Do not flatten the wiki
CC BY-SA component and Jolpica CC BY-NC-SA component into a single dataset claimed to
have only one of those licences. The software and its MIT licence remain separate.
No general permission for commercial redistribution of the Jolpica data is offered.

Season JSON files contain `_provenance`; their exact reviewed bytes are recorded in
`app/assets/asset-register.json`. The old F1 circuit artwork, photographic previews,
driver graphics and source import commands have been retired. Team logos have been
removed; earlier Git history and previously released artifacts may still contain them,
as history is not rewritten. Original project branding is retained as described above;
a successful asset inventory check verifies the recorded files and hashes, not legal
permission to use every item.
Circuit facts come from two separately licensed files that are combined only when an
image is rendered: `circuits_wikipedia.json` (CC BY-SA 4.0) and `circuits_jolpica.json`
(CC BY-NC-SA 4.0). Every value carries `_provenance` with its source URL, licence and,
for Wikipedia, the article revision. They are refreshed only by the manual
`scripts/fetch_circuits.py`, whose output is reviewed and committed; nothing is fetched
at runtime. The former formula1.com-derived circuit facts and their unverified licence
marker have been removed. Missing or invalid values are left empty, not invented.
The old F1 scraper remains retired. Sporting history continues to refresh from Jolpica.

Old public release assets, Git history and remote caches are separate migration work;
removing a file from this working tree does not remove copies already distributed.
