# Calendar render examples

These PNG previews show the actual 800 × 480 calendar BMP output with
`track_style=relief` and `track_accent=all`. They use the 2026 Spanish Grand Prix,
Czech labels and the Europe/Prague timezone. The decorative extrusion is not
terrain elevation, and the colours do not represent official timing sectors.

map component, not to the entire calendar.
